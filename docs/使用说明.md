# 使用说明 — 雾都疑云 · CoC 智能体跑团助手

> 面向使用者：一页看完「守秘人怎么开团」「玩家怎么入团」。
> 部署与排错见《部署文档》；对应 goal §7 阶段 6.1。

---

## 0. 三条硬规则（先记住这三条，基本不会出问题）

1. **服务端权威**：骰子、HP/SAN、场景全部由服务端裁定后广播，页面只是显示 —— 所有端看到的数值必然一致。
2. **双聊天框**：**剧情** tab 是台上发生的事（KP 描述 / 玩家行动 / 骰子 / 系统提示）；**OOC 闲聊** tab 是桌边聊
   （"我去倒水""这个线索是不是有问题"）。在剧情里说话 = 角色在行动。
3. **AI 只会建议或主持，不会偷偷改数值**：一切数值变更都走工具与规则引擎，且必须带原因；
   全自动模式下 AI 下放检定给你本人投掷，而不是替你掷。

---

## 1. 守秘人（KP）视角

### 1.1 开团（约 30 秒）

1. 打开首页（`http://<主机IP>:8000/`）。
2. 点 **「创建房间」** → 填**房间名**与**你的 KP 昵称** → 「创建并进入」。
   系统生成 **8 位房间短码**，直接把你进入控制台后窗口显示的地址（或第 3 节的局域网地址）发给玩家。
3. 左侧「调查团」面板会实时出现加入的玩家。人都到了，点 **「开团」**（房间状态 waiting → playing）。

### 1.2 KP 控制台三栏

```
┌────────────┬──────────────────────────┬──────────────┐
│ 调查团      │  剧情流（主角）           │  KP 工具箱    │
│ 开团        │  ├ KP 剧情描述（橙边）    │  技能检定      │
│ 场景标题栏   │  ├ 玩家行动（灰边）       │  检定下放      │
│ │ 成员卡片    │  ├ 骰子结果（彩色徽章）   │  AI 建议       │
│ │ HP/SAN 条   │  ├ 系统提示              │  KP 风格       │
│ │ 点开看整卡  │  └ AI 主持（蓝 chip +     │  模组骨架      │
│ └ 红条预警    │     行动切口可点击）      │  检查调查员卡   │
│             │  底部输入框（发剧情）      │  LLM 设置      │
│             │                          │  调整 HP/SAN   │
│             │                          │  存档 / 读档    │
└────────────┴──────────────────────────┴──────────────┘
```

- **场景标题栏**：写清地点/时间（如「1926 年冬 · 莲荷町 · 深夜」），全员可见。它是 AI 的场景上下文，
  切场景时 AI 会自动收束上一幕并生成摘要（玩家版不含真相）。
- **玩家面板**：HP 或 SAN 降到 30% 以下会变红报警；点卡片可拉出整卡（属性 / 武器 / 技能 / 背景）。

### 1.3 掷骰与「检定下放」

| 你要做的事 | 用哪个面板 | 说明 |
| --- | --- | --- |
| KP 自己掷（NPC 行动 / 明骰） | **技能检定** | 选难度三档（常规 / 困难 / 极难），结果全员可见 |
| KP 暗骰（玩家不该看到的） | **技能检定** → 勾选暗骰 | 结果只进你的屏幕（玩家协议层收不到这条消息） |
| 让**玩家本人**掷 | **检定下放** | 填目标（玩家昵称）/ 技能 / 难度 / 缘由 → 玩家屏幕上出现"投掷"按钮 |

> **检定下放为什么重要**：目标值由服务端按角色卡查（卡上没这个技能就用技能表基础值），
> 玩家只按一下按钮，骰子由规则引擎掷 —— 既保证公平，也不会出现"玩家自己报结果"。

### 1.4 改状态与剧情推进

- **调整 HP / SAN**：选玩家 → 填新值（绝对值）→ **必须填原因**（如"被触手击中"）。
  系统会 clamp 到合法范围、落一条状态消息，并在所有端实时刷新血条。
- **发剧情**：在中央输入框直接写。KP 的描述会以橙色边框样式呈现，与玩家行动区分开。
- 没有"回合确认"按钮：**你发剧情就是推进**。玩家偏航就即兴接住，之后软引导回主线。

### 1.5 AI 主持的三种模式（顶栏/工具箱切换，全员可见提示）

| 模式 | 谁在主持 | 适合 |
| --- | --- | --- |
| **纯人工** | 你 | 完全按自己节奏带团 |
| **协同建议** | 你主持，AI 只在**你的屏幕**给 2~3 条候选建议 | 想省脑力又不想交出控制权（建议可采纳 / 编辑 / 重生成 / 丢弃） |
| **全自动** | AI 主持，你可随时插话 | 单人练习、演示、临时没人带团 |

- 协同建议**只发到 KP 连接**，玩家永远看不到 AI 的建议内容。
- 全自动模式下，AI 会按模组骨架推进：主动下放检定、登记线索、推进威胁时钟、切换场景；
  它也会做暗骰和 NI 笔记，这些**只在你屏幕上**。
- AI 连续失败会自动回退为纯人工并在剧情流提示，不会卡住不动。

### 1.6 模组库（让 AI 有剧本可依）

1. 左边/顶栏进 **模组库** → 上传（支持 TXT / MD / DOCX / PDF）。
   上传**只提取文本，不花钱**。
2. 在模组详情页点 **「开始解析」**（可先点「检测模型」确认连通；解析模型可留空 = 用轻任务模型）。
   解析时间视模组大小而定（实测 40 秒 ~ 3 分钟）。
3. 解析结果可**人工校对修改**（结构化分块就地编辑），确认后回 KP 控制台。
4. 在 **「模组骨架」** 面板把该模组挂到本房间（一房一模组，可随时换绑/解绑）。
   挂载后 AI 的叙事会按该模组的人物、线索、时钟推进。

### 1.7 其他面板

- **检查调查员卡**：让 AI 逐卡指出不合理处（技能配不上背景、物品与模组冲突…）。
  **只给建议，不拦开团**。
- **KP 风格**：剧情沉浸 / 规则教学 / 平衡 Keeper 三档，房间内实时切换；
  也能自定义四旋钮（叙事密度 / 规则解释 / 暗骰透明度 / 选项颗粒度）并导出导入 JSON。
  风格**只影响表达，不改骰子与数值**。
- **存档 / 读档**：一键快照（成员 + 卡状态 + 聊天历史），读档回到那一刻。
- **LLM 设置**：填 Key / 模型 / 超时，能「测试连通」「探测模型」，并显示 token 总账与本场消耗。
- **退出房间 / 结束游戏**：见第 3 节。

## 2. 玩家视角

### 2.1 建卡（三步向导，约 1~2 分钟）

顶栏进 **角色卡 → 新建**：

1. **基本信息 + 职业**：姓名 / 性别 / 年龄 / 时代 / 居住地 / 出生地，选职业（160+ 个）。
   页面会实时显示职业点（EDU×4）与兴趣点（INT×2）预算。
2. **属性**：二选一 ——
   - **投点法**：一键掷骰（STR/CON/DEX/APP/POW 掷 3D6×5，SIZ/INT/EDU 掷 (2D6+6)×5），掷完锁定；
   - **购点法**：460 点自由分配八项，单项 15~90，幸运由系统随机生成。
   HP / MP / SAN / 伤害加值 / 移动率由规则引擎按属性算出，不用手填。
3. **技能分配**：按职业本职技能优先分配（有「合计」列与超限红字实时拦截）；信用评级必须落在职业区间内。
   保存后可在详情页补 **背景八要素 / 随身物品 / 武器**。

### 2.2 加入房间

1. 首页点 **「加入房间」**（或在下方"等待中的房间"里直接点加入）。
2. 填 **8 位房间号**（自动大写）、**你的名字**（这个名字就是 KP 面板与 AI 看到的目标名）、
   选一张**角色卡**。
3. 进房后是两栏：左边剧情流（**剧情 / OOC 闲聊** 两个 tab），右边是你的角色卡与技能检定面板。

### 2.3 桌上怎么玩

| 想做的事 | 怎么做 |
| --- | --- |
| 描述行动 | 在「剧情」tab 输入框写自然语言（"我蹲下检查门缝下的粉末"），回车发送 |
| 桌边闲聊 | 切到「OOC 闲聊」tab 再说（KP 采纳时会标注来源，不会假装是角色发现） |
| 技能检定 | 右侧「技能检定」选技能 + 难度 → 掷骰；结果以彩色徽章出现在剧情流 |
| KP 让你掷骰 | 屏幕上会出现带"投掷"按钮的检定卡，点一下就行（目标值由服务端按你的卡算） |
| 看自己状态 | 右侧「我的角色卡」：HP / MP / SAN 实时条（≤30% 变红），点开看完整卡 |
| AI 给的行动切口 | 全自动模式下，AI 会列出 2~4 个选项，直接点即发送；**你也可以完全不理它、自由输入** |

### 2.4 断线与刷新

- 网络抖一下、切到别的标签页**不会**把你踢出房间（断开只算"掉线"，不广播离场）。
- 刷新页面 / 重连后会自动补齐房间状态与聊天历史（按消息序号）。
- 真正想离开：点 **「退出房间」**（会弹确认）。只关网页也算离开，但下次要重新输房间号。

---

## 3. 收场

- **玩家**：点「退出房间」。
- **KP**：控制台右上 **「退出房间」**；想彻底解散房间（清空该房数据）用「结束游戏 / 解散房间」，
  解散会先广播通知再断开全房连接，玩家不会停在"幽灵房间"里。
- **主机**：在启动服务那个窗口按 **Ctrl + C** 停止服务。

## 4. 常见疑问

**Q：AI 没反应 / 一直转圈？**
看剧情流里的系统提示：多半是 LLM 配置不通（会自动降级为纯人工并提示）。
到 **LLM 设置** 点「测试连通」；不想折腾就启用**演示模式**（大厅引导条一键切换），
AI 会用本地固定内容回应，功能流程完全一样。

**Q：AI 会不会剧透 / 偷看我的卡？**
不会。守秘信息（真相、暗骰、NPC 动机、AI 的 KP 笔记）走独立通道，**玩家端协议层就收不到**；
另外还有一道输出过滤器把误写进公开叙事的守秘片段强制摘除。

**Q：骰子能作弊吗？**
骰子与目标值都在服务端算，页面只负责显示；检定下放时玩家只按按钮，无法改数值。

**Q：房间号是什么？**
8 位短码（字母+数字，大小写不敏感）。丢了就问 KP 再要一次。

**Q：我的角色卡能改吗？**
能：角色卡列表 → 进详情页编辑（背景 / 物品 / 武器）；建卡阶段之外的属性与技能不建议频繁改动，
改了以后服务端检定会按新卡值走。
