## 0. 基础：骰子与属性

### 0.1 百分骰（D100）

COC 七版的一切检定都用百分骰，由**两枚十面骰**组成：

| 骰子 | 作用 | 读数 |
|---|---|---|
| 十位骰（tens） | 10、20、30 …… 90、**00** | 提供十位 |
| 个位骰（units） | 0 ~ 9 | 提供个位 |

**结果 = 十位 + 个位**，范围 01–100。`00 + 0` 读作 **100**（不是 0）。

例：十位骰出 `40`、个位骰出 `5` → 结果 45。十位骰出 `00`、个位骰出 `3` → 结果 3。

> 奖惩骰（第 4 节）正是基于此结构：多加一枚**十位骰**，然后挑一个十位来用。

### 0.2 八项属性

属性是调查员的能力基石，全部以百分比形式表示（规则书 p.23–25）。

| 属性 | 缩写 | 生成方式 | 取值范围 | 含义 | 归零后果 |
|---|---|---|---|---|---|
| 力量 | STR | 3D6×5 | 15–90 | 肌肉力量；能举多重、抓多牢 | 卧床不起的病号 |
| 体质 | CON | 3D6×5 | 15–90 | 健康、生气、活力；抗病抗毒 | **死亡** |
| 体型 | SIZ | (2D6+6)×5 | 40–90 | 身高与体重的合并值 | 肉体消失 |
| 敏捷 | DEX | 3D6×5 | 15–90 | 迅捷、灵敏、柔韧；决定战斗先攻 | 神经紊乱，无法行动 |
| 外貌 | APP | 3D6×5 | 15–90 | 肉体吸引力 + 人格魅力 | 令人厌恶，走到哪都引发骚动 |
| 智力 | INT | (2D6+6)×5 | 40–90 | 学习、理解、分析、解谜能力 | 如婴儿般流涎的傻瓜 |
| 意志 | POW | 3D6×5 | 15–90 | 心意之力；抵抗魔法的资质 | 行尸走肉，无法施法 |
| 教育 | EDU | (2D6+6)×5 | 40–90 | 正规知识储量（非机智） | 新生儿 / 失忆者 |

**幸运（Luck）**：投 **3D6×5**（规则书 p.37）。它不是八属性之一，但独立参与幸运检定，并可被消耗（见 7.1）。

**关键派生关系速记**

- STR + SIZ → 伤害加值（DB）与体格（BUILD）
- CON + SIZ → 生命值（HP）
- POW → 理智值（SAN）与魔法值（MP）
- INT × 2 → 兴趣技能点数；教育等属性 → 职业技能点数（由职业决定）

### 0.3 半值与五分之一值

难度等级直接建立在「半值 / 五分之一值」上（第 2 节），定义为**向下取整**：

```
半值        = INT(属性或技能 / 2)
五分之一值  = INT(属性或技能 / 5)
```

角色卡实现：每个属性右侧两格即为这两值，如 `W3 = INT(STR/2)`、`W4 = INT(STR/5)`、`AC3 = INT(DEX/2)`、`AI4 = INT(POW/5)`。

例：STR 65 → 半值 32、五分之一值 13。（角色卡直接给出，无需心算）

### 0.4 年龄调整（建卡时）

投完属性先不定稿，先决定年龄再调整（规则书 p.37–38）：

| 年龄 | 调整 |
|---|---|
| 15–19 | STR 与 SIZ 合计 −5，EDU −5；**幸运骰两次取较高** |
| 20–39 | EDU 增强检定 ×1 |
| 40–49 | STR/CON/DEX 合计 −5，APP −5，MOV −1；EDU 增强检定 ×2 |
| 50–59 | STR/CON/DEX 合计 −10，APP −10，MOV −2；EDU 增强检定 ×3 |
| 60–69 | STR/CON/DEX 合计 −20，APP −15，MOV −3；EDU 增强检定 ×4 |
| 70–79 | STR/CON/DEX 合计 −40，APP −20，MOV −4；EDU 增强检定 ×4 |
| 80–89 | STR/CON/DEX 合计 −80，APP −25，MOV −5；EDU 增强检定 ×4 |

**EDU 增强检定**：投 1D100，若结果 **大于** 当前 EDU，则 EDU **+1D10**（上限 99）。

## 1. 衍生值公式

### 1.1 生命值（Hit Points, HP）

```
HP = INT( (CON + SIZ) / 10 )      // 向下取整，舍去小数
```

角色卡：`G10 = INT((U5+U7)/10)`（U5=CON，U7=SIZ），`E10 = G10`。

例：CON 60、SIZ 80 → HP = 14。

### 1.2 魔法值（Magic Points, MP）

```
MP = INT( POW / 5 )
```

角色卡：`Y10 = INT(AG3/5)`（AG3=POW），`W10 = Y10`。

**消耗与恢复**（规则书 p.148）

- 施法、激活造物、为魔法通道充能都要消耗 MP。
- **MP 归零后继续消耗 → 1:1 扣减耐久值（HP）**，表现为疼痛、起泡、七窍流血等，按伤害与医疗规则处理。
- **自然恢复：每小时 +1 点**；POW ≥ 100 每小时 +2 点；POW ≥ 200 每小时 +3 点，以此类推。
  角色卡：`AA11 = INT(POW/100 + 1)`。
- 自然恢复**不能超过** POW 的五分之一上限；额外获得的 MP 可以花，但花掉就没了。

### 1.3 理智值（Sanity, SAN）

```
初始 SAN = POW
最大 SAN = 99 − 克苏鲁神话技能值
```

角色卡：`P10 = 99 - R27`（R27 = 克苏鲁神话技能），`N10 = IF(POW > P10, P10, POW)`。

**要点**：当前 SAN 永远不能超过最大 SAN。每当克苏鲁神话技能增长，立刻把增长值从最大 SAN 中扣除。详见第 6 节。

### 1.4 幸运（Luck）

```
幸运 = 3D6 × 5
```

- 15–19 岁的调查员投两次取较高（见 0.4）。
- 幸运值在游戏中会增减，**上限 99**，且**不会重置**为初始值（规则书 p.84）。
- 可以 1:1 花费幸运改变一次检定结果（可选规则，见 7.1）。

### 1.5 移动力（MOV）

**第一步：由 STR、DEX 与 SIZ 的比较得出基础值**（规则书 p.37）

| 条件 | 基础 MOV |
|---|---|
| DEX 与 STR **皆小于** SIZ | 7 |
| DEX 或 STR **其中之一 ≥** SIZ，或两者**皆等于** SIZ | 8 |
| STR 与 DEX **皆大于** SIZ | 9 |

**第二步：减去年龄减值**

年龄 40–49 → −1；50–59 → −2；60–69 → −3；70–79 → −4；80–89 → −5。

角色卡实现：`AF10 = AI11 + 8`，其中 `AI11 = 附表!C9`，而
`附表!C9 = E8 − C8 − C7`：

- `E8`：STR/DEX 与 SIZ 的比较结果（两者皆大 → +1，皆小 → −1，否则 0）
- `C8`：护甲减值（护甲减值为「关」时计 0）
- `C7 = IF(年龄<40, 0, INT(年龄/10) − 3)`：年龄减值

例：STR 70、DEX 60、SIZ 65（两者皆大于 SIZ → +1），年龄 52（−2），无护甲 → MOV = 8 + 1 − 2 = **7**。

### 1.6 体格（BUILD）与伤害加值（DB）

由 **STR + SIZ** 查表（规则书 p.38）：

| STR + SIZ | 伤害加值 DB | 体格 BUILD |
|---|---|---|
| 2–64 | −2 | −2 |
| 65–84 | −1 | −1 |
| 85–124 | 0 | 0 |
| 125–164 | +1D4 | 1 |
| 165–204 | +1D6 | 2 |
| 205–284 | +2D6 | 3 |
| 285–364 | +3D6 | 4 |
| 365–444 | +4D6 | 5 |
| 445–524 | +5D6 | 6 |

**超过 524 后**：合计值每再超过一个 80（不足 80 按 80 算），DB **+1D6**、体格 **+1**。

角色卡实现（`附表` 列 N/O/P）：

- `N5 = STR + SIZ`
- `N7` = 基础体格（按上表分档）
- `O7 = INT((N5 − 285) / 80)`，`P7 = 最终体格`
- `N9` = 伤害加值文本（体格 ≥ 2 时进入 D6 档），`O10 = "+" & (P7−1) & "D6"`

**含义**：DB 是加到近战伤害骰上的加值（可为负）；BUILD 用于对抗推挤、压制等需要比较体量的判定。

### 1.7 重伤、昏迷与恢复

由**单次攻击造成的伤害**与最大 HP 比较得出（规则书 p.101–103）：

| 判定 | 条件 | 后果 |
|---|---|---|
| 轻伤 | 伤害 < 最大 HP 的一半 | 无严重影响；HP 归零时昏迷，**不会因轻伤死亡** |
| 重伤 | 伤害 ≥ 最大 HP 的一半 | 标记重伤栏 → **立即倒地** → 必须过**体质检定**以免昏迷 |
| 必死 | 伤害 > 最大 HP | 直接死亡 |

- **重伤线（重伤值）** = `CEILING(最大HP / 2, 1)`（向上取整）。角色卡：`D12 = CEILING(G10/2, 1)`。
- **HP 归零**：停止记录伤害（不记负数），角色**陷入昏迷**。若此时重伤栏已标记 → **濒死**（每轮结束需体质检定，不及时急救则死亡）。
- **恢复速度**
  - 轻伤（重伤栏未标记）：每天 +1 HP
  - 重伤（重伤栏已标记）：**每周**一次体质检定 —— 失败 0 点，成功 +1D3，极难成功 +2D3
  - 重伤**治愈条件**：恢复检定达到极难成功，**或** HP 已恢复到最大 HP 的一半以上 → 抹去重伤标记
  - 恢复检定大失败 → 永久性伤害 / 并发症（守秘人决定，如跛行、单眼失明、疤痕）
- **急救**：伤害发生后 **1 小时内**进行，恢复 1 点 HP；只能尝试一次，再试即构成孤注一掷。
- **医学**：成功后额外恢复 1D3 点（濒死者须先过急救再过医学）；重伤者每周恢复检定若接受照料可获得奖励骰。

### 1.8 角色卡衍生值对照表

| 衍生值 | 公式 | 角色卡单元格 |
|---|---|---|
| HP | `INT((CON+SIZ)/10)` | `G10`（显示 `E10`） |
| 重伤值 | `CEILING(HP/2, 1)` | `D12` |
| MP | `INT(POW/5)` | `Y10`（显示 `W10`） |
| MP 每小时恢复 | `INT(POW/100)+1` | `AA11` |
| SAN | `POW`（上限 99−克苏鲁神话） | `N10`，上限 `P10` |
| MOV | 8 + 属性调整 − 护甲减值 − 年龄减值 | `AF10`（调整值 `AI11`） |
| 体格 / DB | STR+SIZ 查表 | `附表!P7` / `附表!P9` |
| 半值 / 五分之一值 | `INT(X/2)` / `INT(X/5)` | 属性右侧两格 |

## 2. 检定阈值（难度等级与成功等级）

### 2.1 三种难度等级

守秘人为每次技能/属性检定设定难度等级，决定**需要通过的目标值**（规则书 p.71–72）：

| 难度等级 | 目标值 | 适用场景 | 使用频率 |
|---|---|---|---|
| **常规** | ≤ 技能或属性的**全值** | 对胜任者构成挑战的一般情形 | 绝大多数情况 |
| **困难** | ≤ 技能或属性的**半值** | 对专业人士构成挑战 | 偶尔 |
| **极难** | ≤ 技能或属性的**五分之一值** | 触及人类可能性边界 | 极端情形，慎用 |

例：图书馆使用 55%

- 常规：投 ≤ 55
- 困难：投 ≤ 27（55/2 下取整）
- 极难：投 ≤ 11（55/5 下取整）

**重要澄清**：一次掷骰只有成败两种结果，没有「部分成功」。投出低于半值/五分之一值**不代表**完成得更好——目标要么充分实现，要么没有（具体解释权在守秘人）。

### 2.2 由对手属性推导难度

面对活物时，难度由**对手的对应技能或属性**决定（规则书 p.72）：

| 对手技能/属性 | 难度等级 |
|---|---|
| < 50 | 常规 |
| ≥ 50 | 困难 |
| ≥ 90 | 极难 |

**原则**：尽量让玩家掷骰。玩家潜行跟踪 NPC → 玩家掷潜行，守秘人用 NPC 的侦查值设难度；反之 NPC 跟踪玩家 → 玩家掷侦查，守秘人用 NPC 的潜行值设难度。

### 2.3 五种成功等级

任何掷骰结果都可归入以下等级（对抗检定直接用于比较，见第 5 节）：

| 等级 | 判定 |
|---|---|
| 大成功 | 投出 **01** |
| 极难成功 | 投出 ≤ 五分之一值 |
| 困难成功 | 投出 ≤ 半值 |
| 常规成功 | 投出 ≤ 全值 |
| 失败 | 投出 > 全值（且非大失败） |
| 大失败 | 见第 3 节 |

### 2.4 社交技能的难度等级

取悦、话术、恐吓、说服四类社交技能，难度由**对方**的对应社交技能或心理学（取较高者）决定，再按态度调整（规则书 p.80）：

| 情形 | 处理 |
|---|---|
| NPC 倾向支持玩家目标 | **不用检定**，直接同意 |
| 对方技能 < 50 | 常规起步 |
| 对方技能 ≥ 50 | 困难 |
| 对方技能 ≥ 90 | 极难 |
| NPC 强烈反对目标 | 难度 **+1~2 级** |
| 玩家有实质支撑（切实论点、持械威胁等） | 难度 **−1 级** |
| 成功率最低的情形 | 极难；极罕见时守秘人可判「根本没有机会」→ 不允许检定 |

### 2.5 组合技能检定

多个技能同时相关时，**只投一次骰**，把结果与每个技能分别比较（规则书 p.79）。守秘人事先声明要求「全部成功」还是「任一成功」。

> 例：机械维修与电气维修都只有 10%。投一次骰两者都要成功 → 概率 10%；若分投两次 → 概率只有 1%。

### 2.6 孤注一掷（Pushed Roll）

技能或属性检定失败后的**第二次也是最后一次**机会（规则书 p.73–74）。

- 玩家必须描述「如何孤注一掷」（额外努力或额外时间），守秘人不直接说行或不行。
- 通常技能与难度等级不变；局势变化时可调整。
- 孤注一掷**不是重骰**，两次检定之间总有时间流逝（几秒到几小时）。
- **不可孤注一掷**：幸运检定、理智检定、战斗检定、伤害与理智损失的掷骰、对抗检定。
- **成功**：与原本检定一样，目标实现，无不良后果。
- **失败**：后果完全由守秘人支配 —— 伤害、理智损失、装备损失、被俘、与同伴失散…… 守秘人甚至可以让目标达成但索取代价。
- **揭示预兆**：孤注一掷前，守秘人可说明「若你失败……」的后果（玩家可要求，守秘人也可主动给出）。
- 检定失败时，玩家在**孤注一掷**与**花费幸运**之间二选一；孤注一掷的结果不能用幸运值改变。

## 3. 大成功 / 大失败

### 3.1 大成功（01）

投出 **01** 即为大成功：目标不仅达成，还附带某种**有利的结果**，由守秘人决定（玩家可建议）（规则书 p.77）。

- 战斗中：击中弱点，造成**最大伤害**。
- 例：估价技能 35%，投出 01 → 不但精确估价，还认出这顶王冠来自南海，可能是马什船长 1830 年代带回的物品之一。

### 3.2 大失败（96–100）

大失败意味着**比单纯失败更糟的事发生**，具体厄运由守秘人决定（规则书 p.77）。

判定规则取决于**本次检定的目标值（上限）**：

| 目标值（需要投出的上限） | 大失败范围 |
|---|---|
| **≥ 50** | 只有 **100** |
| **< 50** | **96–100** |

例：图书馆使用 55% → 只有投出 100 才算大失败。若在黑暗中偷搜图书馆，难度设为困难（目标值 27）→ 投出 96–100 全是大失败。

例：理智检定投出 100 → 大失败 → 受到该次遭遇的**最大**理智损失。

### 3.3 补充要点

- 大失败的冲击**立即生效**，且**不能被孤注一掷无效化**。
- 大成功、大失败与枪械故障**总是**要应用，不能通过花费幸运值改变（规则书 p.84）。
- 百分比技能超过 100 时，大失败范围按 100 以上的目标值处理，仍只有 100 是大失败。

## 4. 奖惩骰（Bonus / Penalty Dice）

### 4.1 是什么

当优势局势、环境或时机明显帮助/妨碍一次检定时，守秘人给予**奖励骰**或**惩罚骰**（规则书 p.78–79）。

它**不是**微调几个百分点：影响小到只值几个百分点就不要管。小雨中驾驶不给惩罚骰；暴雨中雨刮开到满速仍看不清 —— 那才有惩罚骰。

### 4.2 怎么掷

| 类型 | 掷法 | 取用规则 |
|---|---|---|
| **奖励骰** | 额外掷一枚**十位骰**（共：1 个位骰 + 2 个十位骰） | 十位取**较好**（通常较小）的那个 |
| **惩罚骰** | 同上 | 十位取**较坏**（通常较大）的那个 |

例（奖励骰）：取悦 55，个位骰 4，两个十位骰为 40 与 20 → 可选 44 或 24 → 取 24，为**困难成功**。

例（惩罚骰）：STR 55，十位骰 20 与 40，个位骰 1 → 可选 21 或 41 → 必须取 41，仅为**常规成功**。

### 4.3 叠加与抵消

- 绝大多数情况只给 **1 枚**；情势极其有利/不利时可给 **2 枚**。
- **一个奖励骰与一个惩罚骰相互抵消**。
- 掷 2 枚时，从全部十位结果中选最好（奖励）或最坏（惩罚）。

### 4.4 与难度等级的分工

| 检定类型 | 用什么体现优劣势 |
|---|---|
| 技能检定（单人掷骰，如对抗无数据 NPC） | **难度等级**（常规/困难/极难） |
| **对抗检定**（双方同时掷骰，如近战） | **奖罚骰**（不用难度等级，一方的成功等级就是另一方的难度） |

> 守秘人可以把两者结合使用，但应作为特例而非惯例。

### 4.5 副作用

- 使用了奖励骰的检定**不能**获得技能成长标记（规则书 p.80）。
- 花费幸运值改变结果同样不给成长标记。

## 5. 对抗

### 5.1 对抗检定的流程

用于双方互斥地争夺同一结果：两位调查员互相对抗，以及**近战的标准处理方式**（规则书 p.77–78）。战斗之外，守秘人应避免在调查员与 NPC 之间使用对抗检定，除非能增强戏剧性。

1. 双方声明**互斥**的目标（自身胜利 / 对方失败）。
2. 双方各选一项技能或属性（**不必相同**），经守秘人许可。
3. 双方各掷一次百分骰，与自己的值比较，得出**成功等级**。
4. 比较成功等级，高者获胜（见 5.2）。
5. **对抗检定不能孤注一掷。**

> 守秘人注意：属性值通常比技能值高，因此若一方使用属性，另一方应当获得选择属性还是技能的机会。

### 5.2 结果比较

| 优先级（高 → 低） | 结果 |
|---|---|
| 最高 | **大成功**（01） |
| ↑ | **极难成功**（≤ 1/5 值） |
| ↑ | **困难成功**（≤ 半值） |
| ↑ | **常规成功**（≤ 全值） |
| 最低 | **失败** / **大失败** |

即：**大成功 > 极难成功 > 困难成功 > 常规成功 > 失败或大失败**。

例：双方都用智力下棋，都得到常规成功 → 平手进入 5.3。

### 5.3 平手处理

1. **成功等级相同** → **技能（或属性）值更高的一方获胜**。
2. 若仍相同 → **僵局**，或双方重骰。

例：哈维与艾德加都用智力下棋，均为常规成功，艾德加智力更高 → 艾德加胜。

### 5.4 人类极限与合力

**人类极限**（规则书 p.76）

- 对手属性 ≥ 90 → 难度为**极难**；极难成功所能面对的**上限是「100 + 调查员的属性」**，超出即不可能，**不允许检定**。
- 例：STR 40 的调查员不可能在力量对抗中赢过 STR 220 的大型怪物；他最多能尝试的体型上限是 140（= 100 + 40）。

**多人协作突破极限**（仅限 STR / SIZ 这类物理挑战）

1. 把参与者的属性值**由低到高**依次从对手的属性值中**减去**。
2. 减到对手值降到可检定水平后，**未被用于相减**的调查员用自己的属性做检定，难度由对手的**新值**决定（<50 常规 / ≥50 困难 / ≥90 极难）。
3. 对手的属性**不能**被减到 0 或更低，检定总是必要。
4. 若此前已尝试过一次，再次尝试构成**孤注一掷**。

例：屋梁 SIZ 150 压住同伴。塞西尔 STR 40、哈维 20、马丁 45、海伦 60、贝琳达 75。
150 − 20 = 130 → 130 − 40 = 90 → 90 − 45 = **45**（常规难度）。海伦与贝琳达未被用于相减，二人可做检定（孤注一掷），只需一人成功即可。

### 5.5 多人参与同一次检定

- **一人成功即可**的情形（侦查线索、图书馆使用、心理学读心、急救）：每人各掷一次，任一成功即可。
- **全员都要成功**的情形（集体潜行通过守卫）：每人各掷一次，任一失败即暴露。
- 对同一目标的**第二次尝试**原则上需要孤注一掷；换人尝试则要花费额外时间。

## 6. 理智

### 6.1 理智值与最大理智值

| 项目 | 规则 |
|---|---|
| 初始 SAN | = **POW** |
| 最大 SAN | = **99 − 克苏鲁神话技能值** |
| 上限 | 当前 SAN 永远不能超过最大 SAN |

**克苏鲁神话技能每增长一次，立即把增长值从最大 SAN 中扣除**（规则书 p.130）。
例：读古籍获得 +3% 克苏鲁神话 → 最大 SAN 从 99 降为 96。

### 6.2 理智检定

- 触发：遭遇令人不安或恐怖的情景时，守秘人要求场景中每位调查员检定。
- 掷法：投 1D100，**≤ 当前 SAN 即成功**。
- **奖惩骰都不适用于理智检定**（唯一例外是「自救」，见 6.8）。
- 若使用「花费幸运值」可选规则，它同样不适用于理智检定。

### 6.3 理智损失格式

出版物中用斜杠分隔的两个数值表示损失量（规则书 p.129）：

```
SAN 1/1D6
     ↑  ↑
     │  └─ 检定失败时损失的理智值
     └──── 检定成功时损失的理智值
```

- `SAN 0/1D6`：成功不损失，失败损失 1D6。
- 一次失败的理智检定**总是**让调查员瞬间失去行为控制，由守秘人安排一个不由自主的行动（掉落物品、惊叫、猛打方向盘、呆立不动等）。
- **大失败的理智检定** → 受到该次遭遇所能造成的**最大**理智损失。
- 遭遇**多个同类**怪物时，理智损失与遭遇一只时相同（针对「这一遭遇」而非每一只）。可选规则「多重理智检定」：为每只分别掷损失，取最高值。

### 6.4 三种疯狂

| 类型 | 触发条件 | 持续 |
|---|---|---|
| **临时性疯狂** | 一次性损失 **≥ 5 点** SAN，且随后的**智力检定成功**（成功意味着他理解了所见意味着什么 → 崩溃） | **1D10 小时** |
| **不定性疯狂** | 游戏内「一天」内损失 **≥ 1/5 当前 SAN** | 直到治愈或恢复 |
| **永久性疯狂** | SAN 降至 **0** | 永久，角色退出玩家控制 |

- 临时性疯狂的判定很反直觉：**智力检定失败 = 心智压抑记忆 = 不进入疯狂**；**通过 = 认识到真相 = 陷入疯狂**。
- 「一天」的长度由守秘人定夺，一般指到达一个可安全休息、缓释惊吓的场所为止。

### 6.5 疯狂发作：即时症状（1D10）

有其他调查员在场时使用，持续 **1D10 战斗轮**（规则书 p.132–133，角色卡「疯狂表」C4:D13）：

| 1D10 | 症状 |
|---|---|
| 1 | **失忆**：只记得最后身处的安全地点，没有来到此地的记忆，持续 1D10 轮 |
| 2 | **假性残疾**：心理性失明、失聪或躯体缺失感，持续 1D10 轮 |
| 3 | **暴力倾向**：六亲不认，无差别攻击敌友，持续 1D10 轮 |
| 4 | **偏执**：严重偏执妄想（被监视、被背叛、无人可信），持续 1D10 轮 |
| 5 | **人际依赖**：参照背景「重要之人」，把他人误认为那人并据此行动，持续 1D10 轮 |
| 6 | **昏厥**：当场昏倒，1D10 轮后苏醒 |
| 7 | **逃避行为**：不择手段逃离现场（哪怕开走唯一的车抛下同伴），持续 1D10 轮 |
| 8 | **竭嘶底里**：大笑、哭泣、嘶吼等极端情绪，持续 1D10 轮 |
| 9 | **恐惧**：骰 D100 查恐惧症状表（或守秘人指定），即使恐惧源不存在也会在 1D10 轮内想象其存在 |
| 10 | **躁狂**：骰 D100 查躁狂症状表（或守秘人指定），1D10 轮内沉溺于新的躁狂症 |

### 6.6 疯狂发作：总结症状（1D10）

独处、或全场同时发疯时使用，由守秘人概括结果，通常持续 **1D10 小时**（规则书 p.133–134）：

| 1D10 | 症状 |
|---|---|
| 1 | **失忆**：在陌生地点回神，忘记自己是谁，记忆缓慢恢复 |
| 2 | **被窃**：1D10 小时后清醒，被盗但毫发无伤。携带「宝贵之物」时做幸运检定判定是否遗失；其余贵重品自动消失 |
| 3 | **遍体鳞伤**：1D10 小时后清醒，满身拳痕瘀伤，**HP 降为疯狂前的一半**（不构成重伤），未被窃 |
| 4 | **暴力倾向**：强烈的暴力与破坏欲；是否杀人由守秘人决定 |
| 5 | **极端信念**：以极端疯狂的方式展示背景中某项「思想/信念」（如在地铁高声布道） |
| 6 | **重要之人**：1D10 小时或更久内不顾一切地接近背景中的「重要之人」并依关系行动 |
| 7 | **被收容**：在精神病院病房或警察局牢房中回神 |
| 8 | **逃避行为**：在很远的地方清醒（荒郊野岭、开往远方的列车等） |
| 9 | **恐惧**：骰 D100 查恐惧症状表，获得新的恐惧症；1D10 小时后回神并设法避开恐惧源 |
| 10 | **躁狂**：骰 D100 查躁狂症状表，获得新的躁狂症；1D10 小时后回神 |

> 疯狂发作期间**不会**再损失更多 SAN；发作时守秘人可更改或增补调查员的背景条目。

### 6.7 潜在疯狂与现实认知检定

**潜在疯狂**（疯狂阶段 2）：疯狂发作结束后，控制权交还玩家，但精神极度脆弱 —— **任何一丁点（哪怕 1 点）SAN 损失都会再次触发疯狂发作**。临时性疯狂持续 1D10 小时，不定性疯狂可能持续整个模组或战役的一章。

**现实认知检定**（规则书 p.135–136）：潜在疯狂中的调查员会被守秘人灌输幻觉般的感官讯息，唯一鉴别手段是**投 SAN 做现实认知检定**：

- **失败** → 损失 1 点 SAN；若处于潜在疯狂阶段，**立刻引发疯狂发作**，且幻觉不消失。
- **成功** → 看穿幻觉，守秘人如实描述真实所见，并**暂时获得对幻觉的抗性**，直到下一次失去 SAN 为止。

**恐惧症与躁狂症的惩罚骰**：潜在疯狂中，暴露于恐惧源/躁狂诱因时，除战斗或逃跑外的检定**承受 1 个惩罚骰**（不作用于理智检定与现实认知检定），直到远离诱因或彻底屈从于它。一次成功的精神分析检定可暂时摆脱影响。

### 6.8 恢复与增加 SAN

**恢复**

| 情形 | 规则 |
|---|---|
| 临时性疯狂 | 持续 **1D10 小时**；在安全场所好好休息一夜也可恢复（高度紧张地守夜不算） |
| 不定性疯狂 | 每月治疗结束时检定通过才恢复；守秘人也可允许在下一次幕间成长时自动恢复 |

**每月治疗检定（1D100）**

| 方式 | 成功 | 无效 | 失败 |
|---|---|---|---|
| **私人护理** | 01–95：+1D3 SAN，随后做理智检定，**通过则从疯狂中恢复** | —— | 96–100：拒绝治疗，**−1D6 SAN**，且下个月无进展 |
| **收容所** | 01–50：+1D3 SAN，随后理智检定，通过则恢复 | 51–95：无变化 | 96–100：−1D6 SAN，下个月无进展 |

> 收容所的 50 是平均水平，守秘人可依机构质量在 5–95 之间调整。

**增加当前 SAN 的四种方式**（规则书 p.141–142）

1. **守秘人奖励**：完成模组或战役的一章后，守秘人给所有参与者相同的回复骰（如 1D6），每人各自掷。
2. **技能达到 90%**：幕间成长中某项技能增至 90% 及以上 → **+2D6 SAN**（精通带来的自信）。
3. **心理治疗**：每月一次精神分析检定，成功 +1D3 SAN；失败无变化；大失败 −1D6 SAN 且治疗关系破裂。也可用于消除恐惧症/躁狂症（需治疗检定与理智检定双双成功，此时不额外回复 SAN）。
4. **自救**：花时间与背景中某个正面条目（关键连接除外）相处并扮演该场景，然后做理智检定：成功 +1D6 SAN；失败 −1 SAN 且守秘人/玩家应修改该背景条目（如失去信仰、家庭失和）。
   - 若使用**关键连接**做自救，理智检定获得 **1 个奖励骰**（此为奖惩骰适用于理智检定的唯一例外），成功除 +1D6 SAN 外还能**从任何不定性疯狂中恢复**；失败则失去该关键连接，需修改背景。
   - 在理智检定**大成功（01）**时，可立即指定一个新的关键连接。

**SAN 上限提醒**：无论以何种方式回复，当前 SAN 都不能超过最大 SAN（99 − 克苏鲁神话技能）。

### 6.9 习惯恐惧与可选规则

**习惯恐惧**（规则书 p.142）

- 对同一种神话生物，累计 SAN 损失**不会超过该生物单次遭遇所能造成的最大值**（如深潜者 0/1D6 → 上限 6 点）。即便面对百只深潜者也不超此限。
- 玩家应记录各神话存在造成的累计损失；**每次幕间成长时将各项累计值 −1**（时间会重新唤起恐惧）。

**精神固化**（可选，规则书 p.142–143）

当**克苏鲁神话技能 > 当前 SAN** 时触发转变点：调查员对宇宙与自身地位产生根本性理解。此后**所有 SAN 损失减半**，且**永久不可逆**（即使 SAN 后来回复到高于神话技能）。

**多重理智检定**（可选）：遭遇多个神话生物时，为每一只分别掷 SAN 损失，取**最高值**作为本次损失。

## 7. 其它检定

### 7.1 幸运检定

- 适用：结果由**外部环境因素主导**、或要决定「命运之手」时。若有技能或属性适用，应优先使用它们（规则书 p.77）。
- 团体幸运检定 → 由**幸运值最低**的玩家掷。
- **花费幸运值**（可选规则，规则书 p.84）：技能或属性检定后，可 **1:1** 花费幸运改变掷骰结果。花费后幸运值降低，未来通过幸运检定的概率也随之下降。
  - 不可用于：幸运检定、伤害检定、理智检定、决定 SAN 损失的掷骰。
  - 大成功、大失败与枪械故障不能用幸运值改变。
  - 使用幸运值改变结果后**不获得**技能成长标记。
- **回复幸运**：每次游戏聚会后，玩家掷 1D100，**大于**当前幸运值时 +1D10（规则同技能成长检定）。幸运值上限 99，且不会重置为初始值。

### 7.2 智力检定与灵感检定

两者都要求「投出 ≤ 智力值」，但用途不同（规则书 p.78）：

| 检定 | 触发 | 结果 |
|---|---|---|
| **智力检定** | 守秘人要求；破解智力谜题（纵横字谜、谜语等） | 成功 → 从守秘人处获得一份解决方案 |
| **灵感检定** | 玩家在调查陷入僵局时**提议** | 成功 → 轻松找回遗漏的线索；失败 → 也能回到正轨，但要付出某种代价 |

### 7.3 知识检定

代表「脑子里存着什么」，概率等于**教育（EDU）值** —— 投出 ≤ EDU 即成功（规则书 p.78）。

例：没学过化学也知道水不能倒进硫酸；没学生物也知道蜘蛛有几条腿；鉴别当代语言也用它。若有更合适的技能，则优先用技能。

## 8. 幕间成长（技能数值的成长）

### 8.1 成长标记

- 成功使用技能后，在角色卡该技能旁的方框打勾。**使用了奖励骰的检定不能获得标记**；对抗检定中只有**胜者**获得标记。
- 克苏鲁神话与信用评级**永远不会**获得标记。

### 8.2 成长检定

宣布幕间成长后，对每个带标记的技能**各掷一次 1D100**（一项技能无论成功几次，只检定一次）：

| 结果 | 处理 |
|---|---|
| **> 当前技能值**，或结果 **> 95** | 改善：掷 **1D10** 并立即加到技能值上（可超过 100%） |
| **≤ 当前技能值** | 无变化 |

检定完擦掉所有成长标记。

例：潜行 20%，掷出 08 → 不增长。图书馆使用 55%，掷出 68 → 增长，再掷 1D10 得 3 → 变为 58%。

### 8.3 90% 奖励

若某技能经成长后达到 **90% 或以上** → 当前 SAN **+2D6**（规则书 p.81）。

### 8.4 训练

战役中每 **4 个月**游戏内时间，可在同一技能上习得最多 **1D10** 点（规则书 p.84）。

- 完成一阶段训练 → 自动获得一次技能成长检定。
- 学期中参与过多冒险 → 该学期训练无效。
- 自学同理：学习 4 个月后做一次技能成长检定。
